## [Unreleased]

### Изменено

- `ymd-qt`: транспорт, повтор, перемешивание, волна и качество перерисованы.
  Вместо текстовых глифов — Canvas-кнопки `TransportButton` (prev/play/pause/
  next) и иконка синусоиды для «Волны»; повтор/перемешивание/качество —
  Breeze-иконки с подсветкой активного режима.
- Плагин Noctalia называется `ymd`, в описании прямо сказано «неофициальный
  клиент»: бренд больше не используется как название продукта. Технический id
  `pbolkhovitin/yandex-music` сохранён — это ключ в настройках бара, его смена
  требует миграции (см. `LEGAL.md`).
- Архив плагина Noctalia называется `ymd-noctalia-plugin-<версия>.tar.gz`
  вместо прежнего имени с брендом; в `LEGAL.md` добавлена таблица
  идентификаторов и план миграции `id` к 1.0.
- Аудит документации под 0.3.0: macOS-приложение добавлено в README, концепцию
  и архитектуру; в матрице возможностей появилась поверхность `M`, исправлены
  устаревшие статусы перемотки, громкости, обложек и текстов песен; описан
  сброс `rev` после рестарта демона.

### Добавлено

- `ymd-qt`: раздел «Обзор» (`Ctrl+O`) — главная из `/v1/home`, каталог
  жанров и настроений, страница тега с радио, избранное (`kind = 3`) и
  переходы к плейлистам/альбомам/трекам. Демон и API уже поддерживали эти
  данные; теперь они доступны в окне, а не только в Noctalia.
- `ymd-qt`: громкость в виде иконки с вертикальным слайдером, прокрутка
  только очереди, настройки (качество, лимит кэша) и «О программе» с
  авторами и версией.
- Автоматизация документации и версий: `scripts/docs-sync.sh` генерирует
  справочники маршрутов `/v1/*` и полей состояния, `scripts/version-impact.sh`
  считает по коммитам и diff, какая цифра версии следует (major/minor/patch),
  `scripts/release.sh prepare auto` берёт bump из этого отчёта. В CI добавлены
  `docs-sync.sh --check` и сводка влияния на версию в Summary.
- Кодекс поведения участника (`CODE_OF_CONDUCT.md`, Contributor Covenant 2.1):
  порядок приватного сообщения о нарушении и меры; ссылки из `README.md`
  и `CONTRIBUTING.md`. Заполняет пункт Code of conduct в Community Standards.

### Изменено

- Social preview пересобран под текущий состав: «Яндекс Музыка для Linux
  и macOS», строка про macOS Apple Silicon, номер версии берётся из
  `scripts/version.sh`.

## [0.3.0] - 2026-11-15

### Изменено

- Плазмоид: попап показывает все результаты поиска и всю очередь, а не первые
  четыре; высота ограничена `gridUnit * 38`, длинные списки прокручиваются.

### Исправлено

- Релиз: `Cargo.lock` обновляется вместе с версией, иначе `cargo build
  --locked` падал на сборке пакетов; `release.sh check` допускает
  fix-коммиты после release-PR. Поиск релизного коммита больше не падает
  из-за SIGPIPE в `git log | grep -q`.

### Добавлено

- Контролируемый релиз: `scripts/release.sh` (`prepare`, `check`, `publish`,
  `status`) готовит release-PR и запускает `release.yml`; тег и GitHub Release
  создаются только после тестов, сборки и approve environment `release`.
  Release-PR меняет только манифесты версий и `CHANGELOG.md`; `version.sh`
  получил `--next`.
- CI `pr-policy` и `scripts/pr-check.sh`: проверяют оформление PR — заголовок
  в стиле Conventional Commits, разделы шаблона, соответствие галочек «Клиент»
  диффу и новый пункт в `CHANGELOG.md` при правках кода. В шаблон PR добавлен
  macOS; правила для агентов — в `AGENTS.md`.
- Noctalia: подпись в баре настраивается (`label = app|title`), перемотка
  стала слайдером (клик и протяжка), появилась отдельная громкость с mute.
  Отладочные IPC-события `seek` и `volume` для проверки без мыши.
- `docs/15-macos-brief.md` — бриф для внешнего контрибьютора: сборка, запуск,
  правила PR и что прислать после проверки; каталог `/macos/` закреплён за
  `@4epenaxa` в `CODEOWNERS`.
- Social preview для GitHub: `docs/images/social-preview.png` (1280×640) и
  скрипт `scripts/social-preview.sh` для его пересборки.
- Скриншоты в `docs/images/` и раздел «Скриншоты» в `README.md`
  (бар и панель Noctalia на niri).
- Сборка RPM для Fedora: `packaging/build-rpm.sh` собирает демон, плазмоид
  и `ymd-qt` через `rpmbuild` в контейнере; пакеты прикладываются к релизу.
- macOS (Apple Silicon): `packaging/macos/build.sh`, `docs/14-macos.md`,
  `mpris_stub.rs` и `cfg`-разделение модулей — демон собирается под arm64,
  токен хранится в связке ключей (`security`), MPRIS отключён.
- `ymd-menubar`: SwiftUI-клиент для строки меню macOS (обложка, прогресс,
  транспорт, повтор, shuffle) — `macos/build.sh`.
- macOS: `macos/build-dmg.sh` собирает `ymd-menubar-<версия>.dmg` (памятка,
  симлинк на `/Applications`, опциональная подпись `--sign`), вручную или
  через workflow `macos-release.yml`; к релизу прикладывается `.dmg` и
  tar.gz демона arm64.
- Самостоятельный `ymd-menubar.app` для macOS 13+ (Apple Silicon):
  встроенный демон и официальный аудио-runtime GStreamer, запуск демона
  при открытии приложения, вход через Яндекс и «Моя волна» в попапе.
  Упаковщик проверяет arm64, переносимость dylib и минимальную macOS;
  тесты жизненного цикла, звука и TLS — в `macos/Tests/`.
- Отчёт локальной проверки macOS arm64: 43 теста, сборка демона и
  SwiftUI-клиента, запуск HTTP API, аудиопайплайн и целостность DMG;
  ограничения визуальной проверки — `notes/macos-validation-findings.md`.

### Исправлено

- Демон: позиция и `rev` теперь меняются раз в секунду, пока трек играет —
  панель Noctalia получает SSE-события и полоса прогресса двигается, а не
  замирает на моменте открытия. Позиция из прошлой сессии, оставшаяся на
  конце трека, при восстановлении сбрасывается в 0.
- Демон: `advance` (автопереход и защита от перебега) снова грузит поток —
  раньше менялся только индекс, и трек «зависал»; каждый трек играет в
  свежем `playbin3` (старый гасится до `NULL`), поэтому позиция прошлого
  трека больше не наследуется.
- macOS: синтаксис `Button` в SwiftUI-клиенте (явный `label:`); добавлен
  `macos/run-daemon.sh` для запуска с аудиоплагинами без конфликтов
  GTK 3/GTK 4 и Python GI в Homebrew GStreamer.
- Панель Noctalia: обложка не загружалась при открытии — `ensure_cover()`
  вызывался до `refresh()`, когда `cover_url` ещё пуст; теперь вызывается
  в `apply()` сразу после нового состояния.
- CI: `docs-check.sh` валил сборку на правках в `packaging/` — проверка
  «документация не старше кода» теперь гейтит только исходники
  (`daemon`, `plasmoid`, `app`, `noctalia`), а упаковка, скрипты и workflow
  выводятся подсказкой.
- CI: `docs-check.sh` считал merge-коммит (`Update branch` в PR) свежей
  правкой кода и ложно ронял проверку — теперь история смотрится с
  `--no-merges`.
- CI: проверка автора коммита падала на внешнем контрибьюторе — список
  разрешённых адресов в `commit-identity.yml` пополняется при добавлении
  участника (`@4epenaxa` — владелец `/macos/`).
- Релиз `v0.2.1` вышел до появления RPM-сборки — три `.rpm` (демон, плазмоид,
  `ymd-qt`) приложены к нему вручную; следующие теги получают их автоматически.
- Очередь: при `repeat=one` кнопка «следующий» (и `prev`) зацикливала текущий
  трек. Теперь ручной переход всегда идёт дальше по очереди, а `repeat=one`
  действует только на автопереход после конца потока (внутренняя операция
  `advance`).
- «Моя волна» наследовала `repeat=one` и крутила первый трек вместо перехода
  по списку — `wave_start`/`radio_start` теперь ставят `repeat=all` и
  `shuffle=false`.
- CI: сборку `.rpm` можно прогнать вручную (`gh workflow run ci.yml -f packages=true`)
  до выпуска тега.

## [0.2.0] - 2026-11-14

### Добавлено

- Демон `ymd`: OAuth Device Flow и импорт токена из официального клиента,
  токен в GNOME Keyring, capability-ключ `0600` в `$XDG_RUNTIME_DIR/ymd`.
- GStreamer `playbin3` → PipeWire, исходящий MPRIS `org.mpris.MediaPlayer2.ymd`,
  резервный мост к внешним плеерам через `playerctl`.
- API-клиент: поиск, треки, альбомы, исполнители, главная, discovery, радио,
  лайки, тексты песен, «Моя волна» (rotor) с автодогрузкой.
- Поток: подписанный `/get-file-info` (пара «заголовок клиента + ключ»),
  качества `lossless`/`hq`/`nq`, фоллбэк на `hq`, настройка в
  `~/.config/ymd/config.toml`.
- Офлайн-кэш `encraw` + AES-CTR, LRU-лимит, докачка после обрыва
  (`.part` + `Range` + отпечаток ключа).
- Логирование в `~/.local/state/ymd/ymd.log` с ротацией, `ymd logs [-f]`,
  структурные события очереди и EOS.
- systemd user-юнит `ymd.service`, `scripts/install-user-service.sh`.
- Клиенты: плазмоид Plasma 6, приложение `ymd-qt` (Qt 6/Kirigami),
  плагин Noctalia (бар, панель, bridge, тексты, обложки).
- Пакеты `.deb` (демон, плазмоид, `ymd-qt`) и архив плагина Noctalia.

### Исправлено

- Зацикливание одного трека: расчёт следующего индекса вынесен в общий
  `plan_step()`, индекс передаётся в команду — состояние и звук совпадают
  при `repeat`/`shuffle`.
- Виджет Noctalia залипал в «ymd off» после рестарта демона (`rev`
  не монотонен между запусками); «off» теперь только после трёх ошибок.
- Висячий симлинк плагина Noctalia после переименования репозитория:
  `ymd doctor` проверяет ссылку, установщик пересоздаёт её.
