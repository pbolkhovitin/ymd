# Аудит дизайна: панель и бар-виджет yandex-music

Дата: 2026-11-14. Хост: niri + Noctalia 5.4.1, eDP-1 1920×1080, тема
«Kanagawa Paper», шрифт панели — моноширинный (наследуется от хоста).
Скриншоты: `/tmp/opencode/ymaudit/` (`f1c.png` — панель до правок,
`g5c.png` — после, `bar-crop.png` — бар).

## Что измерено

| Параметр | Значение |
|---|---|
| Панель | 483×380 px (~35 % высоты экрана), контент ~443 px |
| Ряды списка | 38 px, `gap = 2` |
| Видимая область списка | ~250 px → 5–6 рядов, дальше скролл |
| Заголовок | 15 px, bold, `on_surface` |
| Артист / вторичный текст | 12 px, `on_surface_variant` |
| Время, подписи секций | 10–11 px |
| Контраст текста | 11.3:1 (заголовок), 8.9:1 (вторичный), 5.1:1 (placeholder) |
| Контраст дорожки прогресса | 1.16:1 (`surface_variant`) → 1.6:1 (`outline/0.4`) |

## P0 — исправлено в этом проходе

1. **Список очереди выходил за границы панели.** Причина: контент лежал в
   `ui.column` без `flexGrow`, список был ограничен `MAX_ROWS = 4`; при 70
   треках терялось 66 позиций, а ряд 4-й обрезался краем панели. Решение:
   корень `ui.column({ flexGrow = 1 })`, списки в
   `ui.scroll({ flexGrow = 1 })`. Проверено: 5 рядов + скроллбар, переполнения нет.
2. **Ряд кнопок режимов шире панели** (130+120+150 px при 396 px контента) —
   «Перемешат…» обрезалось. Кнопки режимов заменены иконками tabler.
3. **Три разных набора глифов** (◀ ▶ ❚❚ ♥ ×, юникод) заменены на один набор
   tabler, один размер (16 px), один stroke.
4. **Состояние «лайк» не отображалось**, хотя `track.liked` есть в API.
   Теперь `heart` / `heart-filled` + `selected`.
5. **Служебный статус в шапке** («paused · FLAC», английский enum) убран;
   осталось название + качество + закрытие.
6. **Прогресс без времени.** Добавлены `0:40 / 4:03` по краям дорожки.
7. **Обрезка ломала кириллицу** (резалось по байтам). Теперь `utf8.len` +
   `utf8.offset`.
8. **Ряды списка выравнивались по центру** (кнопка на всю ширину центрирует
   текст) — «лесенка» из номеров. Теперь `contentAlign = "start"` и номер
   фиксированной ширины `%2d.`; левый край ровный.

## P1 — открытые проблемы

1. **Обложек нет вообще.** Демон отдаёт `track.cover: null` (в результатах
   поиска `cover` есть). Блок обложки не рисуется, шапка схлопывается в одну
   строку — у панели нет визуального якоря, а «сейчас играет» отличается от
   очереди только положением.
2. **Состояние в баре не читается.** Иконка статичная, цвет не меняется;
   `paused` и `playing` выглядят одинаково. В текущей палитре
   `primary ≈ on_surface` (бежевый на бежевом), поэтому заливка цветом не
   спасёт — нужен либо второй глиф, либо `barWidget.setProgress`.
3. **Бар теряет артиста.** Хост обрезает текст виджета по ширине капсулы
   (~22 символа), поэтому «Трек — Артист» превращается в «Трек…». Наш лимит
   в 34 символа не срабатывает: обрезает контейнер.
4. **Плоская иерархия.** В теме всего три текстовых цвета, и
   `on_surface_variant` даёт 8.9:1 против 11.3:1 — визуально это одно и то же.
   Подписи секций, артист и очередь выглядят как основной текст.
5. **Два акцента.** `selected` у повтора/перемешивания заливается тем же
   `primary`, что и кнопка play: на экране две равные «главные» кнопки.
6. **Клавиатуры нет.** `docs/06-design.md` обещает `Space`, `←/→`, `L`, `/`;
   в коде обработчиков нет. Панель Noctalia не забирает фокус клавиатуры
   (проверено uinput-ом: нажатия уходят в активное окно), поэтому шорткаты
   возможны только на уровне бара или через `plugin` IPC.
7. **Состояния загрузки/ошибки — текстом 10 px.** «поиск…», «демон
   недоступен»; при ошибке остаётся устаревший трек, retry нет, скелетона нет.
   `buffering` показывает ▶ вместо статичного `loader-2`.
8. **Нет плейсхолдера обложки.** При отсутствии арта логично рисовать плитку
   44×44 с инициалом артиста, иначе блок «прыгает» при появлении обложки.

## P2 — полировка

9. Поиск без видимой метки (только placeholder) и без очистки; после
   `Enter` фокус не возвращается в поле.
10. В очереди нет длительности, хотя `durationMs` приходит; `✓` (кэш) нигде
    не расшифрован.
11. Низ списка обрезает ряд без подсказки — нет ни fade, ни отступа; при
    скролле колесом это терпимо, но край выглядит «срезанным».
12. Тексты захардкожены по-русски, `plugin/translations/*.json` не используются.
13. Моноширинный шрифт на длинных названиях даёт «телетайп»; 10 px для времени
    ниже комфортного минимума.
14. «ymd off» — внутренний жаргон в баре; для человека это «нет связи».

## Рекомендации по слоям

- **Токены.** Ввести уровень `meta` = `on_surface_variant/0.75` для подписей
  секций и времени; `primary` оставить только play и активному прогрессу;
  `selected` у тумблеров перевести на `secondary`.
- **Типографика.** Тело 12–13, мета 11 (не 10), заголовок 15 bold. Числа
  (время, номера) — моно, названия — обычный шрифт, если хост позволит
  задать `ui.label.fontFamily`.
- **Иерархия.** Шапка: 44 px обложка + (название / артист) + качество + ×;
  транспорт одной строкой; поиск; список. Один акцент — play.
- **Данные.** Пробросить `cover` в `/v1/state` (сейчас `null`); добавить
  `durationMs` в строку очереди; `liked` уже есть — показывать и в баре.
- **Состояния.** `buffering` → `loader-2` (без анимации); ошибка → строка
  `danger` + кнопка «Повторить»; пустой поиск → «Ничего не найдено» с
  подсказкой изменить запрос.
- **Доступность.** Шорткаты вешать на бар-виджет/IPC, а не на панель;
  продублировать иконки tooltip-ами (уже сделано); не кодировать состояние
  только цветом (в баре — глиф или прогресс).
