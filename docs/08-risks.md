# 08. Риски и открытые вопросы

## Риски

| # | Риск | Влияние | Вероятность | Смягчение |
|---|---|---|---|---|
| R1 | Непубличный API Яндекса меняется | среднее | высокая | изоляция в `api.rs`, `serde(default)`, `ymd doctor`, релиз демона без плазмоида |
| R2 | Яндекс блокирует сторонние клиенты | высокое | средняя | честный `deviceId`, заголовки официального клиента, деградация до MPRIS |
| R3 | Нет доступа к lossless на аккаунте | низкое | средняя | `fallback_hq = true`, качество в состоянии фактическое |
| R4 | GStreamer/PipeWire не установлены | среднее | средняя | `Recommends` в .deb, `doctor` подсказывает пакеты, резервный `mpv` |
| R5 | Keyring недоступен (KWallet не настроен) | среднее | низкая | файл `0600` как фоллбэк, предупреждение в `doctor` |
| R6 | Плазмоид не находит ключ | высокое | низкая | retry раз в 5 с, кнопка «Повторить», `ymd session-key` |
| R7 | QML-модули Plasma отличаются в дистрибутиве | среднее | средняя | зависимости .deb, проверка `kpackagetool6`, тест на Ubuntu 26.04 |
| R8 | Демон и plasmashell в разных user-сессиях | среднее | низкая | systemd --user, `XDG_RUNTIME_DIR`, один пользователь |
| R9 | Утечка токена в логи | высокое | низкая | токен не логируется, `doctor` без секретов, gitleaks |
| R10 | Кэш растёт без ограничения | низкое | низкая | `limit_mb`, LRU после каждой загрузки |
| R11 | Клиенты расходятся по UX и поведению | среднее | высокая | `docs/design/ui-rules.md`: общий порядок блоков, токены по ролям, чек-лист в PR |
| R12 | API Noctalia меняется между версиями хоста | среднее | средняя | `plugin_api` фиксирован, `probe.luau` показывает реальные методы, `noctalia plugins lint` |
| R13 | PR одного клиента ломает другой | низкое | средняя | клиенты в отдельных каталогах, `.github/CODEOWNERS`, docs-check по каждому |

## Решения (decision log)

| # | Решение | Альтернативы | Почему |
|---|---|---|---|
| D1 | Rust-демон + QML-плазмоид | всё на QML; всё на Rust | демон умеет аудио/крипту/MPRIS, плазмоид остаётся тонким |
| D2 | HTTP/JSON на `127.0.0.1` | DBus; Unix-socket | просто, отлаживается curl, работает из QML и CLI |
| D3 | Polling 1 с / 3 с | SSE | меньше сложности в QML, состояния небольшие |
| D4 | MPRIS как обязательный интерфейс | только свой протокол | медиа-клавиши и виджет `media` работают бесплатно |
| D5 | Ключ через `ymd session-key` | чтение файла из QML | не нужен доступ к `$XDG_RUNTIME_DIR` из sandbox |
| D6 | Токен только в демоне | токен в плазмоиде | плазмоид не должен видеть секреты |
| D7 | Ноль анимаций | анимации «как в оригинале» | требование пользователя, меньше нагрузки |
| D8 | .deb через Docker + QEMU | нативная сборка на каждой архитектуре | одна машина собирает amd64 и arm64 |
| D9 | Клиенты в одном репозитории, рядом каталогами | отдельные репозитории; плагин в форке | общий демон и контракт, один PR не трогает чужие каталоги |
| D10 | Единые правила UI, разные токены | общая тема для всех; полная свобода | палитра берётся из темы среды, структура и состояния — из `ui-rules.md` |

## Проверки перед релизом

- [ ] `ymd doctor` без ошибок на чистом Ubuntu 26.04.
- [ ] Плазмоид выключается/включается без перезапуска plasmashell.
- [ ] Демон перезапускается — попап восстанавливает состояние.
- [ ] Нет `#rrggbb` в QML и Luau.
- [ ] Нет анимаций в QML и Luau.
- [ ] Нет `sh -c` с пользовательскими данными.
- [ ] Токен не появляется в логах.
- [ ] `.deb` ставится на amd64 и arm64.
- [ ] `noctalia plugins lint ./noctalia` — 0 errors.
- [ ] Панель Noctalia открывается после перезапуска хоста, очередь скроллится.
