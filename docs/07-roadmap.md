Проверено на Ubuntu 26.04: демон собирается в Docker для amd64/arm64,
плазмоид устанавливается через `kpackagetool6` и через .deb, попап
открывается, QML-ошибок нет. На удалённой машине aarch64 проверены
установка и добавление виджета в панель.

## Ближайшие задачи

### 1. Тексты песен

- `api::lyrics()`: подпись `trackId + timeStamp`, запрос `format=TEXT|LRC`,
  второй GET по `downloadUrl`.
- `GET /v1/lyrics?id=`, кэш текста, `ymd lyrics <id>`.
- Кнопка «Текст» в попапе, подсветка текущей строки по `positionMs`
  (без анимации).

Разведка: `notes/lyrics-findings.md`.

### 2. Докачка после обрыва

- `.part` + `Range: bytes=<скачано>-`, проверка размера.
- Не начинать загрузку с нуля, если файл уже частично есть.
- Тест: оборвать соединение на середине, продолжить, сравнить хэш.

### 3. Ynison

WebSocket-синхронизация между устройствами, опционально за флагом.
Не блокирует основной сценарий: без Ynison плеер полностью работает.

### 4. Клиент Noctalia — ✅

Плагин живёт в `noctalia/`, ставится симлинком (`scripts/install-noctalia.sh`).
Панель: обложка, прогресс, транспорт, лайк, режимы, поиск, вся очередь
в `ui.scroll`. Метрики и открытые дефекты — `notes/design-audit.md`.

Дальше по Noctalia:

- обложка: демон отдаёт `track.cover = null` в `/v1/state` — починить в демоне,
  чтобы блок не схлопывался;
- бар: хост режет текст по ширине капсулы (~22 символа) — артист теряется,
  нужен короткий формат или перенос в tooltip;
- пауза и play в баре неразличимы (статичный глиф) — второй глиф или
  `setProgress`;
- состояния загрузки/ошибки — текстом, без retry-действия.

### 5. Отдельное приложение Qt/Kirigami — ✅

`ymd-qt` использует тот же демон `ymd` по HTTP и не дублирует API Яндекса.
Реализованы окно Kirigami, поиск, очередь, транспорт, режимы, трей и
`.deb` для amd64/arm64. Детали — `docs/11-qt-app.md`.

Ограничение: меню трея на Wayland может не открываться при DBus-вызове
`ContextMenu` без input serial; клик по иконке (toggle) и средняя кнопка
(play/pause) работают.

## Порядок

```text
KDE-порт ✅ ──> Qt-приложение ✅ ──> открытие и аккаунт ──> тексты ──> докачка ──> Ynison
```

Тексты и докачка не зависят друг от друга; Qt-приложение использует
стабильный HTTP-контракт, который уже зафиксирован.

Открытие музыки (главная, жанры и настроения, волна по артисту), плейлисты,
избранное и вход через Device Flow в демоне — план и решения в
`docs/12-discovery-account.md`. Первые шаги не меняют UI: API демона
(`/v1/home`, `/v1/discovery/*`, `/v1/auth/*`) и исправление `like`, который
сейчас не ходит в API.

- Плазмоид переживает перезапуск plasmashell и демона.
- `.deb` ставится на amd64 и arm64.
- `scripts/docs-check.sh` → `ok`.
- gitleaks → no leaks.
