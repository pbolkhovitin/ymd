# 05. Паритет с официальным клиентом

Легенда: **V1** — обязательный минимум, **V2** — после первого релиза,
**V3** — желательно, **—** — осознанно не делаем.
Поверхность: `B` — бар, `P` — панель, `D` — только демон/MPRIS.

## Вход и аккаунт

> Фактически реализовано (2026-11-13): вход по токену (keyring), поиск, воспроизведение
> (`raw`-поток), очередь с `repeat/shuffle`, лайк, «Моя волна», офлайн-кэш, MPRIS.
> Ниже — исходная матрица паритета; статусы V1/V2/V3 отражают приоритет, а не готовность.

| Функция | Статус | Где | Примечание |
|---|---|---|---|
| OAuth-вход | V1 | D (P: статус) | свой client_id + loopback; фоллбэк — импорт токена |
| Хранение токена | V1 | D | libsecret, плагин токен не видит |
| Выход / смена аккаунта | V2 | P | профили в keyring |
| Мультиаккаунт одновременно | — | D | `x-yandex-music-multi-auth-user-id` — сложно, не нужно |
| Детский режим | — | — | вне целей |
| Плюс/подписка статус | V2 | P | индикатор в настройках |

## Что теряем сознательно

1. **Chromium-рендерер** — веб-страницы сервиса (промо, блоги) не показываем.
2. **Видео/клипы** — без видеоплеера; только ссылки.
3. **Соцфункции** (профили друзей, комментарии) — вне целей.
4. **Аналитика/телеметрия** — не отправляем ничего, кроме необходимого API.
