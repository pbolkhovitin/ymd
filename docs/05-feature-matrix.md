# 05. Матрица возможностей

Статус на 2026-11-15. Легенда: **✅** — работает, **⏳** — запланировано,
**—** — сознательно не делаем. Поверхность: `B` — компакт в панели,
`P` — попап плазмоида, `D` — демон/MPRIS, `Q` — отдельное приложение Qt,
`N` — бар и панель Noctalia, `M` — приложение в строке меню macOS.

## Вход и аккаунт

| Функция | Статус | Где | Примечание |
|---|---|---|---|
| Вход по токену | ✅ | D, M | `ymd auth login` (Device Flow) или `auth import`; в macOS-приложении — вход из GUI |
| Хранение токена | ✅ | D | keyring, файл `0600` как фоллбэк; плазмоид токен не видит |
| Статус аккаунта | ✅ | D | `ymd auth status` |
| Выход | ✅ | D | `ymd auth logout` |
| Мультиаккаунт | — | D | не нужно для одного пользователя |
| Детский режим | — | — | вне целей |

## Что теряем сознательно

1. **Chromium-рендерер** — промо и блоги сервиса не показываем.
2. **Видео/клипы** — без видеоплеера.
3. **Соцфункции** — профили друзей, комментарии.
4. **Телеметрия** — не отправляем ничего, кроме запросов к API.
