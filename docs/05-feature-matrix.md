**—** — сознательно не делаем. Поверхность: `B` — компакт в панели,

## Что теряем сознательно

1. **Chromium-рендерер** — промо и блоги сервиса не показываем.
2. **Видео/клипы** — без видеоплеера.
3. **Соцфункции** — профили друзей, комментарии.
4. **Телеметрия** — не отправляем ничего, кроме запросов к API.
