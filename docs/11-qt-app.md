# 11. Приложение `ymd-qt`

Отдельное окно на Qt 6 / Kirigami для тех, кому не нужен плазмоид в панели.
Это **тонкий клиент**: токен, API Яндекса, GStreamer, MPRIS и кэш остаются
в демоне `ymd`; приложение общается с ним по локальному HTTP.

## Зачем

- Полноценное окно с обложкой, поиском, очередью, плейлистами и кэшем —
  удобнее попапа.
- Работает одновременно с плазмоидом: оба читают один `/v1/state`.
- Не дублирует авторизацию и не хранит токен.
- Закрытие окна прячет приложение в трей, воспроизведение продолжается.

## Установка

```bash
sudo apt install ./ymd_0.2.0_arm64.deb ./ymd-qt_0.2.0_arm64.deb
systemctl --user enable --now ymd
```

На amd64 — те же пакеты с `_amd64`. Приложение зависит от `ymd` и QML-модулей
Kirigami/Quick Controls; `apt` подтянет их из репозитория.

Запуск:

```bash
ymd-qt
```

Или через меню приложений: **Yandex Music**.

## Сборка

```bash
bash packaging/build-qt-deb.sh --arch amd64   # или arm64
```

Сборка идёт в Docker (`packaging/Dockerfile.qt`, Ubuntu 26.04, Qt 6.10,
Kirigami 6.24). Результат — `dist/ymd-qt_0.2.0_<arch>.deb`.

Тесты бэкенда:

```bash
bash packaging/build-qt-deb.sh --arch amd64   # внутри запускается ctest
```

## Архитектура

| Файл | Что делает |
|---|---|
| `app/src/ymdclient.{h,cpp}` | ключ, HTTP/JSON, polling 1 с/3 с, команды, поиск, плейлисты, кэш, 401-retry |
| `app/src/tray.{h,cpp}` | `KStatusNotifierItem`: показать окно, play/pause, next/prev, выход |
| `app/src/main.cpp` | `QApplication`, тема KDE, связка QML ↔ клиент ↔ трей |
| `app/qml/Main.qml` | окно: обложка, seek, громкость, транспорт, режимы, поиск, очередь, плейлисты (создание/поиск/удаление), кэш, ошибки |
| `app/qml/TrackRow.qml` | строка трека: скачивание, меню `⋮`/правый клик, drag&drop в очереди |
| `app/qml/format.js` | время, качество, кодек/битрейт, размеры кэша, строки треков |

`YmdClient` читает ключ из `$XDG_RUNTIME_DIR/ymd/session.key`; если файла нет —
вызывает `ymd session-key`. Каждый запрос идёт с `X-YMD-Session`. При 401 ключ
перечитывается один раз; повторный 401 показывает ошибку и останавливает polling.
Таймаут запроса — 5 секунд.

Плейлисты и кэш клиент получает через `GET /v1/playlists`, `GET /v1/playlist`
и `GET /v1/cache`; скачивание, удаление и лимит кэша — через команды демона
`download_track`, `download_tracks`, `cache_remove`, `cache_clear`,
`cache_limit`. Прогресс приходит в `state.downloads`, длина очереди — в
`state.downloadPending`; в диалоге плейлиста кнопка «Скачать все» ставит весь
список в последовательную очередь.

Управление плейлистами и лайками идёт через команды `playlist_create`,
`playlist_delete`, `playlist_add_tracks`, `playlist_remove_track`, `like_track`;
демон сам получает актуальный `revision` перед изменением. В detail плейлиста
есть поиск по названию/артисту/альбому и счётчик `N / всего`, удаление
плейлиста и треков, добавление трека в плейлист из контекстного меню.
Очередь можно переставлять drag&drop; позиция, очередь, громкость и качество
сохраняются в `~/.local/share/ymd/state.json` и восстанавливаются после
перезапуска (воспроизведение — по `play`). Статус показывает фактический
кодек и битрейт: `FLAC · 1411 кбит/с`.

## Поведение

- ЛКМ по иконке в трее — показать/скрыть окно.
- Средняя кнопка — play/pause.
- Меню трея — показать окно, play/pause, next/prev, выход.
- Закрытие окна (`X`) прячет его в трей; `Ctrl+Q` завершает приложение.
- Горячие клавиши: `Space` — play/pause, `←`/`→` — seek ±5 с,
  `Ctrl+F` — поиск, `Ctrl+P` — плейлисты, `Ctrl+K` — кэш, `Esc` — скрыть окно.
- Никаких анимаций и `#rrggbb`: только `Kirigami.Theme` и палитра Controls.
  `main.cpp` выставляет `XDG_CURRENT_DESKTOP=KDE`, если переменная пуста, —
  чтобы окно, запущенное не из сессии Plasma, взяло цвета KDE.

## Ограничения

- Меню трея на Wayland может не открываться при вызове через DBus
  (`ContextMenu` без input serial); клик по иконке и средняя кнопка работают.
  Это ограничение окружения, а не логики приложения.
- Приложение не работает без запущенного `ymd`: показывает «Ключ не найден»
  и кнопку «Повторить».
- Обложка грузится по URL; при отсутствии сети остаётся заглушка.
- Пока нет текстов песен, докачки после обрыва и Ynison — как и у плазмоида.
- Полный список плейлистов и менеджер кэша есть только в окне; в попапе —
  выбор плейлиста и скачивание текущего трека.
