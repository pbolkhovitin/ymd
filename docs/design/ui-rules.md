# Дизайн-правила для всех клиентов

Общее для плазмоида Plasma, `ymd-qt` и плагина Noctalia. Платформенные
детали — в `plasma.md` и `noctalia.md`; здесь только то, что не должно
расходиться между клиентами.

## Состояния

| Состояние | Что видно | Запрещено |
|---|---|---|
| `playing` | активная кнопка паузы, прогресс идёт | анимация «пульса», бегущая строка |
| `paused` | кнопка play, прогресс замер | приглушать весь блок до нечитаемости |
| `idle` | «Ничего не играет», пустой трек | показывать прошлый трек |
| `buffering` | статичный индикатор загрузки | вращающийся спиннер |
| `error` | текст ошибки + «Повторить» | оставлять устаревший трек без пометки |
| `offline` | «Нет связи с ymd» + «Повторить» | молчаливое пустое состояние |

Состояние нельзя кодировать только цветом: меняется иконка, подпись или
положение. Ошибка и «нет ключа» — разные тексты, у обоих есть действие
повтора.

## Текст и обрезка

- Обрезка — по кодовым точкам UTF-8, многоточие `…`, без разрыва графем.
- Бюджеты: бар Noctalia ~22 символа (режет сам хост), строка списка — 30 на
  название и 18 на артиста, компакт Plasma — 34.
- Вторичный текст (артист, время, подписи) — не мельче 11 px; 10 px допустим
  только для времени.
- Заголовок — на 1–2 шага крупнее тела, вес bold; ALL CAPS и letter-spacing
  не используем.

## Иерархия и цвет

- Один акцент на экран: кнопка play/pause. Тумблеры (повтор, перемешивание)
  показывают состояние через `selected`/иконку, но не заливаются тем же
  акцентом, что play.
- Мета-текст должен реально отличаться от основного: если тема даёт
  `on_surface_variant` почти равным `on_surface`, применять прозрачность
  (`role/0.75`), а не полагаться на роль.
- Контраст: обычный текст ≥ 4.5:1, крупный и вторичный ≥ 3:1. Дорожка
  прогресса — декоративная, допускается 1.5:1, но заливка обязана читаться.
- Цвета — только из темы платформы: `Kirigami.Theme`, `PlasmaComponents3`,
  `noctalia.getColor(role)`. Никаких `#rrggbb` в коде.

## Прогресс и время

- Дорожка 2 px, заливка — акцент, трек — приглушённый контур.
- Время `m:ss` слева (прошло) и справа (длительность). Одно число без
  второго бесполезно.
- Обновление раз в секунду, без интерполяции между тиками.

## Движение

Ноль анимаций по умолчанию: никаких `Behavior`, `NumberAnimation`, marquee,
fade/slide при открытии. Анимация открытия окна/попапа — настройка хоста,
не наша.

## Иконки

- Один набор на платформу: tabler (Noctalia), Breeze (Plasma), Qt/Kirigami
  иконки из темы (`ymd-qt`).
- Один размерный ряд (16–18 px) и один stroke; эмодзи и юникод-глифы
  (`▶`, `❚❚`, `♥`, `×`) не используем.
- У каждой иконки-кнопки — tooltip и доступное имя.

## Доступность и клавиатура

- Plasma: `Tab` — фокус, `Enter` — активация, `Space` — play/pause.
- Noctalia: панель не забирает фокус клавиатуры — обещать шорткаты в панели
  нельзя; управление мышью, шорткаты на уровне бара и MPRIS.
- Фокус виден, hover не подменяет фокус, размеры контролов берутся из темы.

## Данные

- Клиент не показывает то, чего не получил: `cover: null` → плейсхолдер или
  отсутствие блока без «прыжка» раскладки, а не пустая рамка.
- Поля, которые уже есть в `/v1/state`, используются: `liked`, `durationMs`,
  `quality`, `queue.repeat`, `queue.shuffle`.
- Ошибка сети не стирает последний известный трек, но помечает его как
  устаревший.

## Чек-лист перед PR

- [ ] Длинная очередь и длинные названия не вылезают за панель/попап.
- [ ] Пауза, загрузка и ошибка отличимы без наведения.
- [ ] Время и прогресс совпадают с `/v1/state`.
- [ ] Все иконки — из одного набора, у всех есть tooltip.
- [ ] Нет `#rrggbb`, нет анимаций, нет marquee.
- [ ] Тексты обрезаны по UTF-8 и не ломают кириллицу.
