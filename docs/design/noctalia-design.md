# 06. Дизайн-язык

## Позиция

Интерфейс — **часть бара**, а не приложение внутри бара. Значит: нет рамок, нет
теней, нет своих фонов, нет анимаций. Всё, что рисуем, — текст, один глиф и
тонкая линия прогресса на палитре обоев.

## Токены

| Токен | Источник | Использование |
|---|---|---|
| `text` | `noctalia.getColor("on_surface")` | название трека |
| `text-dim` | `on_surface_variant` | артист, время |
| `accent` | `primary` | состояние `playing`, активная волна |
| `danger` | `error` | ошибка, «нет сети» |
| `track` | `outline` | дорожка прогресса |

Правила:

- Захардкоженных `#rrggbb` в коде нет. Если пользователь задал цвет — только он.
- Контраст: `on_surface` на фоне бара ≥ 4.5:1; `text-dim` ≥ 3:1 (крупный вторичный).
- Прозрачность — `role/0.6` (синтаксис Noctalia), не `opacity` (он гасит и текст).

## Метрики

| Свойство | Значение |
|---|---|
| Высота содержимого | подстраивается под `thickness` бара (34 px на хосте) |
| Глиф | 16 px (`ui.button glyphSize = 16`) |
| Текст | шрифт бара, вес из `bar.font_weight` (400) |
| Размер шрифта | наследуется (не задаём) |
| Отступы | `gap = 6`, `paddingH = 4` |
| Макс. ширина строки | 34 символа в коде; фактически хост режет по ширине капсулы (~22) |
| Прогресс | высота 2 px (`ui.progress height = 2`) |
| Радиус | 0 у себя; капсулу рисует бар |

Панель на 1920×1080 занимает 483×380 px (~35 % высоты): шапка, транспорт,
поиск и список. Всё, что не влезло, живёт в `ui.scroll`; фиксированной высоты
у списка нет.

## Типографика

- Один шрифт — из бара. Никаких `loadFont`, кроме опции «моноширинный».
- Обрезка — многоточием, без marquee и без «бегущей строки».
- Никаких ALL CAPS, letter-spacing, теней текста.

## Состояния

| Состояние | Глиф панели | Текст бара | Акцент |
|---|---|---|---|
| `idle` | `player-play` | пусто | — |
| `playing` | `player-pause` | «Трек — Артист» | `primary` у play |
| `paused` | `player-play` | то же, приглушённо | — |
| `buffering` | `loader-2` (статичный) | трек | — |
| `error` | `alert-triangle` | «ошибка» | `danger` |
| `offline` | `music-off` | «ymd off» | `text-dim` |

В баре иконка статична (`music`) и состояние сейчас не различается: цвет
глифа в текущей палитре совпадает с текстом. Долг — второй глиф или
`barWidget.setProgress`; цветом состояние не кодировать.

«Статичный `loader-2`» — не вращаем: глиф без анимации либо `hourglass`.

## Анимации

По умолчанию — **ноль**. Что запрещено:

- `setNeedsFrameTick` / `onFrameTick` в виджете и панели;
- marquee, fade-in, slide, scale при открытии панели (анимация панели — настройка хоста);
- интерполяция прогресса между тиками;
- подсветка всей плашки при наведении → `hover_highlight = false`.

Если пользователь включил `animations = true`: разрешён только прогресс с
`frameTick` на 60 fps, пока играет; всё остальное остаётся мгновенным.

## Панель

- Один столбец, корень `ui.column({ flexGrow = 1 })`, списки — в
  `ui.scroll({ flexGrow = 1 })`. Без `flexGrow` контент вылезает за панель:
  проверено на очереди из 70 треков.
- Порядок: шапка (название · качество · ×) → артист (и обложка, если есть) →
  дорожка прогресса с временем `m:ss` по краям → транспорт одной строкой →
  поиск → список.
- Транспорт: иконки tabler 16 px, `controlSize = "sm"`, play — единственный
  `primary`; лайк/повтор/перемешивание — `ghost` + `selected`; «Волна» —
  иконка + текст.
- Ряды списка: `ui.button({ variant = "ghost", contentAlign = "start" })`,
  номер `%2d.`, название ≤ 30 символов, артист ≤ 18, обрезка по UTF-8.
  Высота ~38 px, `gap = 2`.
- Разделители не используем: ряды разделяет ритм, а не линии.
- Пустые состояния: одна строка `on_surface_variant` 12 px, без иллюстраций.
- Клавиатурного фокуса у панели Noctalia нет — панель управляется мышью.
  Обещать `Space`/`←/→` в панели нельзя; шорткаты — только на уровне бара.

## Доступность

- Все действия доступны мышью; клавиатурные сокращения живут в баре и
  медиа-клавишах (MPRIS), не в панели.
- Иконки дублируются текстом (tooltip) — `ui.button.tooltip`.
- Никакой информации только цветом: состояние видно и по глифу.
- Уважать `ui.select`/`ui.slider` хост-размеры (`controlSize`), не переопределять
  высоты интерактивных контролов.
- Минимальный кегль текста — 11 px; 10 px допустим только для времени.
