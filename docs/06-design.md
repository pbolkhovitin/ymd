# 06. Дизайн плазмоида

## Позиция

Плазмоид — часть панели KDE, а не отдельное приложение. Компактная часть
показывает трек, попап — управление. Никаких своих фонов, рамок, теней и
анимаций: цвета и размеры берутся у темы Plasma/Kirigami.

## Цвета и токены

| Роль | Источник | Использование |
|---|---|---|
| основной текст | `Kirigami.Theme.textColor` | название трека |
| вторичный текст | `Kirigami.Theme.disabledTextColor` | артист, время, подписи |
| акцент | `Kirigami.Theme.highlightColor` | активная кнопка, текущий трек |
| ошибка | `Kirigami.Theme.negativeTextColor` | «Ключ не найден», ошибки сети |
| фон попапа | `Kirigami.Theme.backgroundColor` | подложка |

Правила:

- В QML нет `#rrggbb` — только `Kirigami.Theme` и `PlasmaComponents3`.
- Иконки — `Kirigami.Icon` / `PlasmaComponents3.ToolButton`, без растровых
  ассетов.
- Контраст обычного текста — не ниже 4.5:1, вторичного — 3:1.

## Метрики

| Свойство | Значение |
|---|---|
| Компакт | иконка `audio-x-generic` + текст, высота панели |
| Макс. текст в компакте | 34 символа, обрезка `…` |
| Ширина попапа | `Kirigami.Units.gridUnit * 24` |
| Обложка | 96×96, скругление 4 px |
| Отступы | `Kirigami.Units.smallSpacing` / `largeSpacing` |
| Слайдер перемотки | стандартный `PlasmaComponents3.Slider` |
| Строка очереди | `PlasmaComponents3.ItemDelegate`, высота по теме |

## Компактная часть

- Иконка `audio-x-generic`.
- Текст `Трек — Артист`, обрезается через `format.js`.
- Tooltip: полное название, артист, статус, качество.
- ЛКМ — открыть/закрыть попап.
- СКМ — play/pause.
- Колесо — previous/next.
- ПКМ — стандартное меню Plasma (не перехватываем).

## Попап

Сверху вниз:

1. Обложка, название, артист, статус и качество.
2. Слайдер перемотки и время `0:00 / 0:00`.
3. Транспорт: previous, play/pause, next, like, «Волна», закрыть.
4. Режимы: repeat, shuffle, quality.
5. Поиск: поле ввода и до четырёх результатов.
6. Очередь: до четырёх строк, текущий трек подсвечен.
7. Ошибка и кнопка «Повторить», если состояние не загрузилось.

Пустые состояния — одна строка вторичным цветом: «Введите запрос»,
«Ничего не найдено», «Очередь пуста».

## Состояния

| Состояние | Компакт | Попап |
|---|---|---|
| `playing` | иконка + трек | активный play/pause |
| `paused` | приглушённый текст | кнопка play |
| `stopped` | «Ничего не играет» | пустой трек, `0:00` |
| нет ключа | «Ключ не найден» | ошибка + «Повторить» |
| ошибка HTTP | «Нет связи с ymd» | текст ошибки + «Повторить» |

## Анимации

По умолчанию — **ноль**. Запрещены `Behavior`, `NumberAnimation`,
marquee, fade/slide при открытии. Прогресс обновляется раз в секунду
без интерполяции. Анимация открытия попапа — настройка Plasma, не наша.

## Доступность

- Все действия доступны мышью и с клавиатуры: `Tab` — фокус, `Enter` —
  активация, `Space` — play/pause в поле без фокуса.
- Иконки дублируются tooltip-текстом.
- Состояние видно не только цветом: play/pause меняет иконку, качество
  подписано текстом.
- Размеры интерактивных элементов не переопределяются — берутся из темы.

## Ограничения

- Плазмоид не пишет в свой каталог и не кэширует обложки на диск.
- Сетевые запросы асинхронны; UI не блокируется.
- Ключ читается только через `ymd session-key`.
