# Самостоятельное приложение macOS

Согласованный сценарий: пользователь переносит приложение из DMG в
«Программы», открывает его, входит через браузер Яндекса из попапа и
включает «Мою волну». Homebrew, Rust и терминал на целевом Mac не нужны.

Дополнительное требование пользователя: macOS 13 Ventura+ на Apple Silicon.
Библиотеки из Homebrew текущего хоста требуют 27.2, поэтому используются
официальные бинарники GStreamer 1.28.8 (arm64 minimum 11.0). Сборка
останавливается при любом вложенном Mach-O с minimum новее 13.0.

## Состав

`Contents/MacOS/ymd-menubar` — SwiftUI-клиент.
`Contents/Helpers/ymd` — встроенный Rust-демон.
`Contents/Helpers/gst-plugin-scanner` — сканер GStreamer.
`Contents/Frameworks/` — рекурсивно собранные несистемные библиотеки.
`Contents/Resources/gstreamer-1.0/` — только аудиоплагины.
`Contents/Resources/gio/modules/` — TLS-модуль GIO OpenSSL.
Все Mach-O зависимости перенаправляются внутрь bundle; сборка прерывается
при оставшихся внешних зависимостях или конфликте имён библиотек.

## Жизненный цикл

Клиент сначала проверяет доступность существующего ymd через health и
аутентифицированный state. Если демон отсутствует, запускает Helpers/ymd
через Foundation Process без shell. Окружение аудио задаётся только ребёнку.
Ожидание готовности асинхронное и ограничено таймаутом. Ошибка видна в UI,
повторный запуск доступен кнопкой. При выходе останавливается только свой
процесс, внешний демон остаётся работать. Падение своего демона показывается
в UI; повторный запуск не создаёт дубликаты процессов.

## Вход и музыка

Используются существующие `/v1/account`, `/v1/auth/device` и `/v1/cmd`.
Клиент отображает код Device Flow, открывает HTTPS-страницу Яндекса в
браузере, опрашивает результат, позволяет отменить ожидание. Токен остаётся
у демона в Keychain. Для пустой очереди доступна «Моя волна» (`wave_start`).
Существующий HTTP-контракт и порт 8765 сохраняются.

## Проверка

Перед интеграционной проверкой останавливаются все запущенные ymd и
ymd-menubar — это явно разрешено пользователем. Проверяются запуск только
из .app, новый процесс из Helpers, HTTP, отсутствие внешних dylib,
завершение собственного процесса и сохранение внешнего. Runtime проверяется
с чистым PATH и отключёнными путями плагинов Homebrew; отдельно проверяются
плагины аудио и HTTPS. DMG проверяется hdiutil, подписи — codesign.
Developer ID и notarization в этот этап не входят. Публикация в форке разрешена пользователем;
версия приложения сохраняется 0.2.1.
